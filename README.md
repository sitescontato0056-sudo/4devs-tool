# 4Devs TOOL

Painel dark & clean para Termux — geração e validação de dados brasileiros.

## ⚠️ Aviso
Todos os dados são fictícios, apenas para testes de software.

## 📱 Instalação

    pkg install python git -y
    git clone https://github.com/SEU_USUARIO/4devs-tool.git
    cd 4devs-tool
    pip install -r requirements.txt
    python painel.py

## ✨ Recursos
- Geração: pessoa, CPF, CNPJ, RG, CNH, PIS, título, veículo, placa, RENAVAM, cartão, conta, certidões
- Validação: CPF, CNPJ, CNH, título, PIS, cartão (Luhn)
